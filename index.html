청소용품 앱

관리자에게 받은 연결 링크가 있으면 그 링크를 누르세요. 바로 연결돼요.

중간에 다른 창(Apps Script)을 다녀와야 해요. 이 화면은 닫지 말고 크롬·사파리 탭으로 열어두세요. 카카오톡 안에서 열었다면 오른쪽 위 메뉴 → 다른 브라우저로 열기.

1서버 코드 복사

자동 복사가 안 되는 브라우저예요. 아래 칸을 길게 눌러 전체 선택 → 복사 해주세요.

2Apps Script에 붙여넣기

Apps Script 새 프로젝트 열기 ↗
  1. 편집기가 안 보이거나 '앱을 설치하라'고 나오면 브라우저 메뉴(⋮ 또는 가A)에서 데스크톱 사이트를 켜세요.
  2. 편집기 글자를 길게 눌러 전체 선택 → 붙여넣기. 원래 있던 function myFunction()은 지워져야 해요.
  3. 위쪽 💾 저장 아이콘을 누르세요.

3웹 앱으로 배포

  1. 오른쪽 위 파란 배포 → 새 배포
  2. '유형 선택' 옆 ⚙ → 웹 앱
  3. 다음 사용자 인증 정보로 실행: 나
    액세스 권한이 있는 사용자: 모든 사용자
  4. 배포 → 액세스 승인 → 내 계정 → 고급 → …(으)로 이동(안전하지 않음) → 허용
  5. 나온 웹 앱 URL 아래 복사를 누르고 이 화면으로 돌아오기

'안전하지 않음'은 내가 직접 만든 코드라 구글이 따로 검사하지 않았다는 뜻이에요. 이 코드는 내 드라이브에 시트 하나를 만들고 거기에만 씁니다.

4주소 넣고 설치 마치기

✓설치 완료

내 구글 드라이브에 청소용품 요청 시트가 만들어졌어요. 앱에서 등록하면 여기에 쌓여요.

구글 시트 열어보기 ↗

시트도 같이 보게 하려면 구글 시트 앱에서 공유 → 지역장님 구글 이메일 추가 (선택). 앱만 쓸 거면 안 해도 돼요.

수량

쿠팡에서 고른 상품의 공유 → 링크 복사 후 붙여넣기. 비워두면 품명으로 검색 링크가 붙어요.
