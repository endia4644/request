# 청소용품 요청 앱

휴대폰으로 필요한 청소용품을 적으면 → 구글 시트 `청소용품` 탭에 한 줄로 올라가고,
**품명 바로 옆 칸에 쿠팡 링크**가 자동으로 붙습니다. 같은 링크를 받은 사람(지역장 등)은
15초마다 자동으로 새로고침되는 같은 목록을 봅니다.

```
휴대폰 앱 (index.html, GitHub Pages)
   │  등록 · 상태 변경
   ▼
Apps Script 웹 앱 (Code.gs)  ← 서버 역할. 구글 시트에 붙어 있음
   │
   ▼
구글 시트 '청소용품'
  등록일시 | 현장 | 품명 | 쿠팡 | 수량 | 등록자 | 상태 | 메모 | (ID 숨김)
```

- **쿠팡 링크**: 쿠팡 상품 링크를 같이 넣으면 그 상품, 안 넣으면 `쿠팡에서 품명 검색` 링크.
  쿠팡 앱 → 공유 → 링크 복사한 문구(`[쿠팡] 상품명 https://link.coupang.com/…`)를 통째로 붙여넣어도 주소만 뽑습니다.
- **휴대폰에서 쿠팡 열기**: `쿠팡에서 찾기`는 **쿠팡 앱**을 먼저 열고, 앱이 없으면 모바일 쿠팡(m.coupang.com)으로 갑니다.
  열 때 품명을 복사해 두므로 앱이 검색어 없이 열리면 검색창에 붙여넣으면 됩니다.
  (www.coupang.com 검색 주소는 휴대폰 사파리에서 '사용권한이 없습니다'로 막힙니다. 시트의 링크는 컴퓨터용이라 그대로 둡니다)
- **상품 링크 붙이기**: 쿠팡에서 상품 고르고 **공유 → 링크 복사** → 앱으로 돌아오면 아래에 **📋 링크 붙이기** 안내가 뜹니다.
  누르면 그 품목에 상품 링크가 붙고 시트에도 반영됩니다. 카드의 **링크 붙이기** 버튼, 등록 칸의 **📋 붙여넣기**도 같은 일을 합니다.
  공유 문구를 통째로 붙여도 주소만 남고, 품명 칸이 비었으면 상품 이름을 채웁니다. (아이폰은 '붙여넣기' 확인 말풍선이 한 번 뜹니다)
- **상태**: `요청` → `주문완료` → `입고완료`. 앱에서 버튼 한 번(주문했어요 / 받았어요).
- **시트에서 직접 적어도 됩니다**: 품명 칸에 적으면 쿠팡 링크·등록일시·상태가 자동으로 채워집니다.
- 입고완료는 90일 지나면 앱 목록에서만 빠지고 시트에는 남습니다.
- **날짜별 목록**: 목록이 등록한 날짜로 묶여 보입니다 (`오늘 · 11월 16일 (월) 3건`).
- **월별 합계**: 목록 위 `월별 합계` → ‹ › 로 달 이동. 전체 요청·주문함·받음·아직 요청 건수, **품목별 합계**(몇 번, 수량 합계 — `2통`+`4통`=`6통`),
  현장별 건수, 날짜별 건수(누르면 그날 목록으로). 맨 아래 `○월 엑셀로 받기`.
- **엑셀 내보내기**: 앱 위쪽 ⬇ 버튼 (또는 ⋮ → 엑셀로 내보내기). 기간(이번 달 / 지난 달 / **직접**(날짜 범위) / 전체)·상태·현장을 골라
  `.xlsx`로 받습니다. 90일 지난 입고완료도 포함됩니다. 휴대폰에서는 공유 창이 떠서 '파일에 저장'이나 카톡으로 바로 보낼 수 있습니다.
  시트 두 장: **목록**(등록일시 | 현장 | 품명 | 수량 | 상태 | 등록자 | 메모 | 쿠팡 링크)과
  **품목별 합계**(품명 | 요청 횟수 | 수량 합계 | 요청 | 주문완료 | 입고완료 | 쿠팡). 머리 줄 고정 + 필터 켜짐.
  하루에 몰아 적을 필요 없이, 날마다 등록한 것이 쌓이고 아무 때나 기간을 골라 받으면 됩니다.
  > 카카오톡 안에서 링크를 열면 파일 받기가 막힐 수 있습니다. 홈 화면에 추가한 아이콘이나 크롬·사파리로 여세요.

## 설치 — 휴대폰만으로 (5~10분)

컴퓨터 없이 됩니다. 시트는 설치할 때 **자동으로 만들어지고**, 팀 코드도 자동으로 정해집니다.

**0. GitHub Pages 켜기 (처음 한 번, 1분)**
휴대폰 크롬/사파리로 https://github.com/endia4644/request/settings/pages 열기 → (로그인) →
Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**.
GitHub 앱에는 이 설정이 없으니 브라우저로 여세요. 화면이 잘리면 브라우저 메뉴에서 **데스크톱 사이트**를 켭니다.

**1~4. 앱이 단계별로 안내합니다**
1~2분 뒤 https://endia4644.github.io/request/ 를 크롬/사파리로 열고 **처음 설치하기**를 누르면:

1. **코드 복사하기** 버튼 → 서버 코드가 통째로 복사됨 (`Code.paste.gs` — 주석을 뺀 붙여넣기용)
2. **Apps Script 새 프로젝트 열기** → (데스크톱 사이트 켜기) → 편집기 전체 선택 → 붙여넣기 → 💾 저장
3. **배포 → 새 배포 → ⚙ 웹 앱** → 실행: **나** / 액세스: **모든 사용자** → 배포 →
   **액세스 승인 → 고급 → …(으)로 이동(안전하지 않음) → 허용** → 웹 앱 URL **복사**
4. 앱으로 돌아와 주소 붙여넣기 → **설치 마치기**
   → 내 드라이브에 `청소용품 요청` 시트가 생기고, **지역장님께 연결 링크 보내기** 버튼이 나옵니다 (카톡 공유).

> 'Apps Script'를 휴대폰으로 열면 편집기가 작게 보이거나 앱 설치를 권할 수 있습니다. 브라우저의 **데스크톱 사이트**를 켜면 됩니다.
> 연결 링크에는 팀 코드가 들어 있습니다. 팀 밖으로 보내지 마세요.
> 팀 코드를 잊었으면: Apps Script → 왼쪽 ⚙ **프로젝트 설정** → 아래 **스크립트 속성**의 `TEAM_KEY`.

## 설치 — 컴퓨터에서 시트에 붙이는 방식 (선택)

이미 쓰는 시트에 붙이고 싶을 때. 시트 → **확장 프로그램 → Apps Script** → `Code.gs` 붙여넣기 → 저장 →
시트 새로고침 → 메뉴 **청소용품 앱 → ① 처음 설정** → 웹 앱으로 배포 → **② 휴대폰 연결 링크 만들기**.
(이 방식은 그 시트의 `청소용품` 탭을 씁니다)

## 링크가 두 개인 이유

- **앱 링크 (GitHub)** — `https://endia4644.github.io/request/#c=…` 화면이 깔끔하고 홈 화면 아이콘이 붙습니다.
  GitHub에 `endia4644/request` 저장소의 Pages가 켜져 있어야 열립니다.
- **예비 링크** — Apps Script 주소 그대로. GitHub Pages가 꺼져 있어도 열리지만(화면은 GitHub에서 받아 옴) 위에 구글 안내 줄이 붙습니다.

## 코드를 고친 뒤

- `Code.gs`를 고쳤으면 **`node tools/build_paste.js`** 로 `Code.paste.gs`를 다시 만들어 같이 커밋.
  (휴대폰에서 붙여넣으면 `//` 주석 끝 줄바꿈이 사라져 다음 줄 코드가 주석에 먹히는 일이 있어서, 주석 없는 버전을 붙여넣는다)

- Apps Script에 다시 붙여넣고 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**.
  (새 배포를 만들면 주소가 바뀌어 연결 링크를 다시 보내야 합니다.)
- GitHub Pages 쪽은 `index.html`을 저장소에 올리면 1~2분 뒤 반영됩니다.

## 검증 (이 저장소에서)

```bash
node test/test.js     # Code.gs 를 가짜 시트로 돌림 (24개, 휴대폰 설치 포함)
CODE_FILE=Code.paste.gs node test/test.js   # 붙여넣기용도 똑같이
node test/e2e.js      # 휴대폰 두 대로 등록 → 실시간 반영 → 상태 변경 → 엑셀 → 빈 서버에 처음 설치까지
node test/serve.js    # http://localhost:8787 개발 서버 (가짜 시트, 팀 코드 testkey123)
STANDALONE=1 node test/serve.js   # 빈 서버 — 처음 설치 화면 확인용 (주소 http://localhost:8787/api)
```

구글 서버 위에서의 실제 동작(권한 승인·배포·HYPERLINK 표시)은 이 컨테이너에서 돌릴 수 없으니
처음 설치 후 화면을 확인할 것.

## 한도

- Apps Script 무료 계정은 하루 실행 시간 90분. 앱은 화면이 켜져 있을 때만 15초마다 한 번 읽으므로
  두세 명이 쓰는 데는 넉넉합니다 (화면을 꺼두면 멈춤).
